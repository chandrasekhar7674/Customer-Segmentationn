# Customer Segmentation 📊

A Machine Learning project that groups customers into different segments using K-Means Clustering.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- K-Means Clustering

## Features Used

- Annual Income
- Spending Score

## Machine Learning Process

1. Load customer data
2. Select relevant features
3. Standardize the data
4. Use the Elbow Method
5. Apply K-Means Clustering
6. Analyze customer groups
7. Visualize the clusters
